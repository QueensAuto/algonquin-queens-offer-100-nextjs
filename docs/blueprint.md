# **App Name**: Auto Savings Hub

## Core Features:

- Instant Savings Code: Generates a unique savings code based on the estimated repair cost entered by the user. The code is valid for a limited time to encourage booking.
- Tiered Discount Calculator: Calculates tiered discounts (e.g., $15 off $100+, $30 off $200+) based on the estimated repair cost using the cost slider, and displays the savings amount and final cost in real time.
- AI-Powered Savings Suggestions: Uses a generative AI tool to suggest specific services or combinations of services that will help customers reach the next savings tier.  The tool provides cost-effective recommendations for maximizing their discounts.
- Appointment Booking Form: A two-step form where users enter their contact information, vehicle details, and preferred appointment date and time. Validates input and allows users to select an available time slot from the calendar.

## Style Guidelines:

- Primary color: Saturated blue (#3b82f6), reflecting trust and automotive expertise.
- Background color: Dark grayish blue (#1e293b), evoking a modern and sophisticated feel.
- Accent color: Analogous blue-purple (#a855f7), to highlight calls to action and important information, drawing attention without being jarring.
- Headline font: 'Plus Jakarta Sans' sans-serif, for bold and modern headlines.
- Body font: 'Inter' sans-serif, used to ensure readability and clarity throughout the application.
- Lucide icons with a thin stroke to maintain a consistent visual style. Icons related to cars, discounts, and repair services
- Sections divided to provide enough contrast to distinguish between logical separation
